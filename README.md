# fetchenv

Fetch encode/decode helpers for env payloads in pipelines.

**Site:** https://theworker02.github.io/fetchenv/

## Install / run

```bash
git clone https://github.com/theworker02/fetchenv.git
cd fetchenv
node src/cli.js
node --test
```
